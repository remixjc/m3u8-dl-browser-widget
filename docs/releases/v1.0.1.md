# M3U8 下载助手 v1.0.1

新增 `hls.m3u8` 捕获与页面标题命名，继续配合现有 m3u8-dl WebUI 使用。

## 更新

- 同时捕获 URL 路径文件名为 `playlist.m3u8` 和 `hls.m3u8` 的请求，完整保留签名与查询参数。
- `hls.m3u8` 使用顶层页面标题作为保存名称与子文件夹，不截取标题中的视频编号；自动清理文件名非法字符，最长 100 字符，支持确认前修改。
- 保留 `playlist.m3u8` 原有的视频编号命名方式。
- 弹窗标签与网页提示显示实际捕获的文件名，更新安装说明与产品介绍页。
- Referer 仍使用捕获时的地址栏网址，User-Agent 仍使用指定固定值。

## 安装与升级

下载 `m3u8-download-helper-v1.0.1.zip` 并解压。已安装用户覆盖原插件文件夹后，在 `chrome://extensions` 点击「重新加载」，再刷新视频网站。

新站点或 CDN 若不在默认域名内，请点击插件设置中的「为其他网站开启捕获权限」，授权后刷新播放页面。安装包附带 SHA-256 校验文件。

## 验证与范围

验证包含严格文件名过滤、标题清理、重复捕获更新标题、签名 URL 保留、下载参数交接，以及模拟 WebUI 和弹窗的浏览器检查。未提供具体新站点地址，尚未在该站点进行实际联调。

捕获使用本机网络，下载仍由 m3u8-dl 服务执行；Docker 需要能访问视频 CDN。
