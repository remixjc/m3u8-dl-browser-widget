# M3U8 下载助手 v1.0.2

优化 `hls.m3u8` 的名称长度与归档目录。

## 更新

- 页面标题清理后保留前 20 个 Unicode 字符，不追加省略号；空标题沿用「未命名视频」。
- 自动命名、手动修改、旧缓存和下载表单交接统一执行长度限制，文件名与标题子目录保持一致。
- `hls.m3u8` 保存到下载根目录下的 `hls/`，默认路径为 `/app/downloads/hls/<短标题>`。
- 关闭「按视频名称创建子文件夹」时，保存目录为 `/app/downloads/hls`。支持 Linux、Windows 与 UNC 根路径。
- `playlist.m3u8` 的编号命名和保存目录规则保持不变。

## 升级

下载 `m3u8-download-helper-v1.0.2.zip`，覆盖原插件文件夹，在 `chrome://extensions` 中点击「重新加载」，再刷新视频页面。根目录和网站设置无需修改。

已创建的下载任务与已有文件保留原名称和位置；以上规则适用于新发送的任务。视频扩展名由 m3u8-dl 决定，不计入插件的 20 字符名称限制。

## 验证

验证覆盖 19、20、21 字符边界、中文和 emoji 截取、文件名安全处理、旧缓存、手动名称，以及跨平台目录和关闭标题子目录的行为。Chrome 模拟表单检查验证两种清单的名称、路径与请求头交接。
