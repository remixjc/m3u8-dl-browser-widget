# M3U8 下载助手 v1.0.0

首个正式版本，配合 [lzwme/m3u8-dl](https://github.com/lzwme/m3u8-dl) WebUI 使用，无需修改已有 Docker 下载服务。

## 功能

- 在本机 Chrome 中仅捕获文件名为 `playlist.m3u8` 的请求，保留签名与查询参数。
- 从播放页地址或标题识别视频编号，自动生成文件名与独立保存目录。
- 点击插件确认后打开已部署的下载网站，自动填入下载参数；可选自动开始下载。
- Referer 固定使用捕获时的地址栏网址，User-Agent 固定为 `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36`。
- 提供网页提示、工具栏资源列表、站点权限设置及下载网站密码等待处理。

## 安装与升级

下载本次发布的 `m3u8-download-helper-v1.0.0.zip`，解压后在 Chrome 的 `chrome://extensions` 中开启开发者模式，点击「加载已解压的扩展程序」，选择解压出的 `m3u8-download-helper` 文件夹。

已安装旧版时，将新文件覆盖到原插件文件夹，点击扩展程序的「重新加载」，再刷新视频页面。请保留原文件夹路径，以继续使用原插件配置。

首次使用请填写你的 m3u8-dl 网站地址与 Docker 内的下载根目录，默认为 `/app/downloads`。附带 `.sha256` 文件用于校验安装包。

## 打包与验证

- 新增无第三方依赖的跨平台 ZIP 打包命令和 SHA-256 校验文件。
- 标签发布自动检查版本一致性、逻辑与打包测试、Chrome 模拟表单流程，再创建正式 GitHub Release。
- 安装包仅包含插件运行文件、README 和界面截图，不含 Git 数据、测试浏览器配置、开发脚本或本机设置。

## 使用范围

浏览和捕获使用本机网络，实际下载由 m3u8-dl 服务执行，因此 Docker 仍需能够访问视频 CDN。此版本通过逻辑测试与模拟页面浏览器检查，具体站点和已部署 WebUI 版本的兼容性需以实际使用为准。
